النسخ الاحتياطي والربط مع Google Drive

اربط حساب Google لحفظ نسخة احتياطية من قاعدة بيانات الجمعية في مجلد ظاهر باسم «نسخ احتياطي جمعية الخلفية» داخل Google Drive.

يتطلب الربط إعداد Google OAuth Client ID وتفعيل Google Drive API لموقع HTTPS. لا تدخل كلمة مرور Google داخل هذا البرنامج؛ ستظهر نافذة Google الرسمية للموافقة.
لم يتم ربط حساب Google بعد.
تغيير بيانات الدخول يخص حسابك الحالي. لا تشارك كلمة المرور. الحماية الحالية محلية داخل المتصفح وليست بديلاً عن خادم آمن متعدد المستخدمين.

استيراد ملفات الهاتف إلى قاعدة بيانات البرنامج

اختر ملف Excel أو CSV أو JSON من ذاكرة الهاتف. سيقرأ البرنامج الملف محلياً، ويتعرف على عناوين الأعمدة العربية والإنجليزية، ويعرض معاينة قبل الحفظ. لا تُرفع الملفات إلى الإنترنت.
قوالب الأعمدة المقترحة: المزارعون (رقم العضوية، اسم المزارع، القرية، الهاتف، الانتساب)؛ المحاصيل (رقم العضوية، المحصول، المساحة، البذور، الإنتاج، الموسم، التاريخ)؛ المخزون (الكود، الصنف، الكمية، الوحدة)؛ الحسابات (رقم العضوية، البيان، مدين، دائن، التاريخ).

تنبيه مهم: البيانات محفوظة محلياً في هذا الهاتف/المتصفح. الإدخال والتعديل والتقارير والنسخ الاحتياطي JSON واستيراد CSV/JSON تعمل دون إنترنت. استيراد وتصدير Excel يتطلبان تحميل مكتبة Excel عند توفر الإنترنت أول مرة. تعدد الأجهزة ومزامنة البيانات بينها يتطلبان خادماً آمناً غير مفعّل في هذه النسخة. احتفظ بنسخة JSON احتياطية دورياً.
